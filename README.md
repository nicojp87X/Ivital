# Ivital · Web oficial

**Herbolario y espacio de salud integral en Las Palmas de Gran Canaria.**
Web estática 100% HTML/CSS/JS vanilla. Sin build, sin frameworks, sin dependencias de servidor.

> *Otra forma de Vida es posible. Cuídate desde dentro.*

---

## 📁 Estructura

```
Ivital/
├── index.html              # Landing principal
├── aviso-legal.html        # Páginas legales RGPD
├── privacidad.html
├── cookies.html
├── robots.txt              # SEO crawlers
├── sitemap.xml             # SEO indexación
├── img/                    # Imágenes optimizadas (WebP)
├── Landing/                # Versión original de trabajo
├── Publicaciones/          # Piezas Instagram publicadas (PNG)
├── Publicaciones_pendientes/  # Slides en HTML pendientes
├── CONTEXT.md              # Contexto técnico del proyecto
└── CLAUDE.md               # Configuración de modelos y marca
```

## 🚀 Deploy

**Local (preview):**
```bash
python3 -m http.server 8000
# Abrir http://localhost:8000
```

**Producción:** se publica en `ivital.es` (Hostinger).
Push a `main` dispara el workflow `.github/workflows/deploy.yml`.
